背包

刀、马槊、弓各自装备一件武器，仅对应形态生效；防具、战靴、护符始终生效。装备随主线跨章继承，重试恢复章首。未拾取装备在通关时自动收入。

操作与数值

六章分别有六、五、四、四、五、五段阻击，每章各有一名无名叛军骁将。简单模式开场30骑，困难模式3骑，随行唐军自主跟随、交战并可能阵亡；生命100、冲锋15，受到箭矢伤害×2。己方骑兵场上最多2名，本批全部阵亡后才补下一批，援军骑兵也共用此上限。敌军每批最多6名（最多2骑），清完后间隔1.25秒补下一批。骁将HP1000、冲锋150，生命与攻击为五倍；速度与前摇不倍率放大。清除当段敌军后继续向右，前五章击败骁将并抵达出口完成本章；第六章击败攻城军骁将后，尹子奇以10000生命登场，打至1000生命即接入睢阳陷落PV。他有五套带前后摇的招式，地面预警后才造成伤害。此决战为剧情演绎。

第二章断指立即扣20血；之后180秒内每10秒扣2血，共18次，带入第三章。暂停与PV不消耗伤势时间；格挡和冲刺不能免除伤势。第三章简单模式获赠100匹战马、困难模式10匹，记入补给，不增加骑兵人数。宁陵三千步骑按历史叙事记录；返城时身边加入6名步兵与6名骑兵，援军步兵生命80、伤害8；援军骑兵同样生命100、冲锋15，排入两骑轮换队列。主线继承状态及幸存队伍；终章按史实呈现睢阳陷落。

U：刀“回风三叠”，三次近身斩击各为刀普攻0.9倍，短步前进75；马槊“破阵贯槊”，普攻4倍，直线前冲320并拖拽。I：刀“断阵横斩”，前方340×200宽幅斩击，普攻3.5倍并击退击倒；马槊“挑龙震地”，挑空1倍 + 范围砸地2倍。弓U/I各消耗1箭，直击均为弓普攻1倍，U穿透附火，I箭雨僵直1.5秒。跳攻2倍、反击3倍；箭命中骑兵翻倍。U/I冷却各8秒，O冷却15秒，各形态共享。

O：8秒内直接伤害×1.5、命中附火、近战按实际扣血量吸血10%；箭、灼烧与友军伤害不吸血，过量伤害不计。每秒消耗自身当前生命5%。灼烧每层持续5秒，单层每秒由敌人当前生命2%随南霁云失血线性增加，南霁云≤20%生命时达到10%；同一敌人按统一秒拍结算，所有层合计每秒封顶其当前生命10%，不再乘食人魔伤害加成。Boss有韧性时仍减免10%。

Boss韧性：普通关底100，尹子奇300；韧性>0时免击退、拖拽、挑飞、击倒、僵直并减伤10%。直接攻击削韧，灼烧不削韧；反击削韧×2、砸地与断阵横斩×1.6、箭雨×0.5。打空后4秒可控制、无韧性减伤，随后韧性全恢复。破韧当次按命中前状态减伤。

装备：步兵18%、弓兵22%、骑兵45%掉率，连续7次无掉落后的第8次必掉；关底必掉珍品及以上；第五章关底必掉陌刀，逼退尹子奇赠名器。F拾取，Tab打开背包手动装备。武器提高对应形态普攻及技能，防具增加生命上限和减伤，战靴增加移动速度，护符增加生命与攻击。装备有独立唐式外观，角色同步换装。陌刀为最强长柄，对骑兵直击×1.5、削韧×1.5。更换生命装备保留当前生命百分比；同槽不叠加。旧版主线进度可读取，v7使用独立存档。

刀：撩100 → 砍180 → 抹145 → 刺205 → 力劈华山160；槊：刺240 → 掠220 → 挑200 → 砸180。最后一段命中击倒1.5秒。每段动作中可再点J预存下一段，最后一段可接回第一段。A / D 可在攻击前摇与收招阶段转向，连招按当前方向继续；同时按住A和D时以后按下的方向为准。收招后0.55秒内也能续接。短按L骑乘冲刺中点J，刀劈砍为普攻2倍；马槊发动400距离贯穿拖拽，普攻1.5倍；长按L疾驰不加伤。B每次拔一支扣5生命，满囊不拔不扣；生命不足仍可拔箭并导致倒下。L 按住满 0.22 秒进入奔跑，松开即止；不足 0.22 秒松开触发一次冲刺。单独长按 L 朝面向跑。奔跑没有无敌。正面格挡全额挡伤；冲刺期间短暂无敌；按 H 原地上下马；满载时箭留在尸体上。
